# Business rules: explicit and inferred

This register records **explicit enforced rules** separately from **observed behavior inferred from code**. `BRW-` IDs are SRS analysis IDs, not a renumbering of code comments such as `BR-PM-01`. Each `IMPLEMENTED` row cites the condition or write that enforces it. A comment or plan alone is not counted as implementation. Future changes are in a separate table. Source-level confirmation does not establish behavior in a separately deployed environment.
