## Shared record and system dependencies

- **Identity and authorization:** all protected HTTP workflows depend on an active user and JWT, with fixed role checks and selected service checks. CEO bypass and absence of general ABAC affect every handoff (**IMPLEMENTED** current gate; **PLANNED** replacement). Sources: `src/app.module.ts:78–83`; `src/modules/auth/jwt.strategy.ts:29–47`; `src/common/guards/roles.guard.ts:15–33`; `docs/srs/DECISIONS.md:7–8`.
- **Squad membership:** PM authority for payroll, loans, purchases/bookings and task review depends on active `SquadMembership`; removal/transfer can change that authority during a workflow (**IMPLEMENTED**). Sources: `src/modules/payroll/payroll.service.ts:125–131`, `:243–252`; `src/modules/loans/loans.service.ts:24–30`; `src/modules/marketplace/marketplace.service.ts:78–83`; `src/modules/consultancy/consultancy.service.ts:30–36`; `src/modules/tasks/tasks.service.ts:468–481`.
- **Settings and finance:** current sprint, lab budget, payout schedule/rates, loan threshold/interest, fees and consultant cap are read from `SystemSetting` with code fallbacks. Financial workflows share `Account`, `LedgerTransaction` and `LedgerEntry` (**IMPLEMENTED**). Sources: `src/modules/settings/settings.service.ts:17–49`, `:138–140`; `src/modules/payroll/payroll.service.ts:125–150`; `src/modules/sprint-payouts/sprint-payouts.service.ts:24–61`; `src/modules/loans/loans.service.ts:35–58`; `src/modules/ledger/ledger.service.ts:55–183`; `prisma/schema.prisma:360–410`.
- **Health and technical gates:** daily squad health and computed tech score can block marketplace purchases and consultancy bookings; loan default also sets bankrupt-risk health (**IMPLEMENTED**). Sources: `src/modules/dashboard/dashboard.service.ts:76–184`, `:334–397`; `src/modules/loans/loans.service.ts:62–87`; `src/modules/marketplace/marketplace.service.ts:89–100`; `src/modules/consultancy/consultancy.service.ts:37–47`.
- **Event delivery:** task, payroll, governance, milestone and balance paths publish Socket.IO events after selected state changes; subscription room authentication/ownership is absent (**IMPLEMENTED source exposure**, not authorized visibility). Sources: `src/modules/tasks/tasks.service.ts:42–69`; `src/modules/payroll/payroll.service.ts:301–317`; `src/modules/governance/governance.service.ts:26–40`; `src/modules/clients/clients.service.ts:231–238`; `src/modules/ledger/ledger.service.ts:188–197`; `src/events/events.gateway.ts:25–39`.
