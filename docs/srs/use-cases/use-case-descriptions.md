# ERP use case descriptions

The detailed use cases are split into seven domain files to keep each description readable: [identity](identity.md), [work](work.md), [people](people.md), [finance](finance.md), [technical](technical.md), [clients](clients.md) and [operations](operations.md). The [index](use-case-index.md) maps every functional requirement to a use case or an explicit non-interactive classification.

Each description includes ID, goal, actors, trigger, preconditions, main and alternative flows, exceptions, postconditions, business rules, related requirement IDs, status and evidence. Current RBAC and planned ABAC are distinguished in the index and descriptions. The editable [PlantUML diagrams](../diagrams/use-cases/) present one overall view and six perspectives; CPO shows current source actions while target grants remain unresolved.
